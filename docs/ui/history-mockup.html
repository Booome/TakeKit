录制历史：三个布局方案

三张图是同一个 900 × 640 面板（缩放 62%），内容、配色、字号全部相同 —— 只有历史的位置不同。 录完的那一刻，三张图都处在「刚刚保存」的状态，所以你能看到各自的完成后反馈长什么样。

  • 整行可点 = 打开目录（含键盘 Enter），hover / 按下 / focus-visible 三种反馈都有；⟶ 只是提示，不是唯一热区。
  • 路径省略左边、保留结尾：真正有用的是 take 目录名（2026-10-19-15-23-37），不是 C:\Users\…。悬停给完整路径。
  • 失败的那次也进历史，用橙色三角标记 —— 否则「录了但没成功」会变成一条你找不到的出入口。
  • 空状态给一句引导，不留白。

A · 底栏上方的「最近一次」

参数区下面常驻一条 44px 的细条，只放最近一次录制；右侧「全部历史」开浮层看更早的。 源列表的空间一点没动，和今天完全一样。

适合：绝大多数时候你只关心「刚录的那条」。代价：更早的记录藏在浮层里。

B · 历史占下半屏

源区缩到上面一小块（1–2 行，多了自己滚），下面整块是历史，能一眼扫到最近五六次。 源和历史同屏，都不用点。

适合：你会连着录几段、回头挨个找。代价：源多时两边都紧张。

C · 顶部标签「源 / 历史」

标题栏下加两个页签，历史独占整个内容区，可以按今天 / 昨天 / 更早分组、放很多条。 录完在「历史」上点一个小蓝点，提示有新记录。

适合：你想把历史当正经列表翻。代价：源和历史不能同时看到。
