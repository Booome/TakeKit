三张图都是真实的 900 × 640，100% 缩放，没有裁切也没有留白 —— 面板永远铺满窗口。 左「源」（就是今天的样子，只是顶上多了页签行）、中「历史」、右「日志」。 最左那张右上角浮着一个提示窗：它固定在那里、压在所有内容之上，盖住什么都不会让下面的东西挪动。

  • 提示是一个固定位置的浮窗：贴在右上角、压在所有层级之上（包括「添加源」浮层），出现就把底下的东西盖住；它不参与布局，所以内容一动不动。5 秒后自己收起，点 × 立刻关 —— 关掉也不丢，同一条已经在「日志」页签里。
  • 「日志」只记需要你注意的事（警告 / 错误，例如某个源失效、编码器拒绝奇数尺寸、找不到 ffmpeg）。成功的「已保存」不进日志，它归「历史」。
  • 失败的那次（12:41）也在历史列表里，橙色三角；不知什么时候就丢了的失败记录，是这里最容易找不到的出入口。
  • 路径压成「盘符 + … + take 目录名」（C:\…\2026-10-19-15-23-37）：每行重复一遍 C:\Users\…\AppData\Local\Temp 只是噪声，而 CSS 只能砍右边、恰好砍掉唯一认得出的那截。完整路径在悬停提示里。
  • 整行可点 = 打开目录（含键盘 Enter），⟶ 只是提示；hover / 按下 / focus-visible 三态反馈都有。
  • 页签右边的点 = 有新内容没看过：绿（历史里有新的成功录制）、橙（日志里有新的警告）；切到那个页签才消失，不自动切页签。

「源」页签

和现在完全一致，只是头顶多了一行页签。右上角那个提示窗压在最上层、盖住底下的行 —— 这是有意的，它 5 秒后自己走，或点 × 立刻关。

超长时（同一套样式，3 行收口）

已移除 3 个不可用的源：微信、Chrome、记事本 —— 这些窗口在录制开始前就已经关闭或不在当前桌面，因此没有参与本次录制，需要的话请重新添加；这次只录到了剩下的那一路。（可能是被最小化到了托盘，也可能只是切了虚拟桌面。）

浮窗只放一句结论，最多 3 行，再长就在这儿收口成省略号；完整内容永远在「日志」里，点开就能看全。

「历史」页签

按今天 / 昨天 / 更早分组，默认保留最近 20 条；刚录的那条标「新」并高亮一圈，页签上的绿点等你切过来才消失。

「日志」页签

只留警告和错误，按天分组、新的在上。想知道某次为什么失败，点「查看日志」就能打开那次录制自己的日志。
